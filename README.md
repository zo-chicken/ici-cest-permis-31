# Ici c'est Permis 31 · site vitrine

Site de l'agence de location de voitures à double commande Ici c'est Permis 31 (PMH, Toulouse).

Page unique statique : `index.html` + `logo.png`, publiée avec GitHub Pages.

- Coordonnées (téléphone, e-mail) : constante `CONTACT` en bas de `index.html`.
- Tarifs : constante `PACKS` (prix TTC boîte manuelle / automatique).
